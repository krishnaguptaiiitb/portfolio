Selected work

How do you make revoking access as easy as sharing?

Problem

Files are encrypted in the browser, so nothing on screen shows who can still open them. Security that people can't see is security they can't trust.

Decision

Every recipient sits in one list with one clear action. Revoking re-encrypts the file key, so the screen and the real access always match.

Why it helps the user

People never have to wonder if a removal worked. The row tells them.

What should a student see when time is running out?

Problem

Timed exams stress people. A countdown alone gives no help, and a sudden auto-submit feels unfair. Used by 250+ students across multiple colleges.

Decision

The timer escalates in stages: calm, a plain warning with a next step, then a clear confirmation once answers are submitted.

Why it helps the user

No one is surprised. Each state says what is happening and what to do.

How do 100+ people follow a ranking that keeps changing?

Problem

When a live leaderboard jumps, players lose track of where they are and why.

Decision

Rows slide to their new position and show the points just gained, so the change can be followed with the eye.

Why it helps the user

Players see their own movement, which keeps a fast game readable.

    Can you understand an algorithm by watching it run?

    Problem

    Scheduling algorithms are usually taught as tables. The differences between them are hard to feel.

    Decision

    The same four processes run under each algorithm. Switching redraws one timeline, so comparison is direct.

    Why it helps the user

    Learners spot the difference themselves instead of memorising it.
